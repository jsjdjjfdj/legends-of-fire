# LEGENDS OF FIRE — Free Fire Esports Tournament Platform

## Features Included
- **Premium Fire Dark Gaming UI** (`#080808` / `#151515` / `#FF6A00` / `#FF3B00`)
- **Official LEGENDS OF FIRE Logo & Favicon** embedded directly inside the application
- **16:9 YouTube Thumbnail Promo Slider** & Bengali Announcement Marquee
- **8 Match Mode Categories** (BR Match, E-Sports Mode, Lone Wolf, Lost to Win, Solo, Duo, Squad, Custom Room) with Admin Image Customizer
- **Tournament Registration & RLS-Protected Room ID / Password Unlocking**
- **Players Hiring Marketplace** (Role filtering + Direct WhatsApp & In-App Hire)
- **Dual Esports Shop** (Instant UID Diamond Top-Up & Pro Gaming Products)
- **Virtual Debit Wallet Card, Profile Photo Upload & 4 Payment Methods** (bKash, Nagad, Rocket, Upay)
- **Sign In & Sign Up Authentication UI**
- **Admin Command Center** (Triple-tap the `LEGENDS OF FIRE` logo in the top header or sign in with `admin@legendsoffire.gg`)

## Quick Start & Deployment
- **Local Preview:** Double-click `index.html` (or `legends-of-fire-esports.html`) to open in any browser.
- **GitHub / Vercel / Netlify:** Upload `index.html` to your repository root and deploy as a static site—zero build step required.
